## 系統需求
- Windows 10／11（64 位元）
- 系統管理員權限（斷線保護需要；每次啟動會跳出一次 UAC）
- 不需安裝 Python 或其他元件；VPNBook 模式另需安裝 [WireGuard](https://www.wireguard.com/install/)

## 下載與第一次啟動
1. 從 [Releases](https://github.com/AIXAI-tools/AIXAI-VPN/releases) 下載 `AIXAI-VPN_vX_Y_Z_Windows_x64.exe`
   - 建議放在固定的資料夾（例如 `文件\AIXAI-VPN\`），之後程式內更新會直接替換這個檔案
   - 想確認檔案沒被竄改：PowerShell 執行 `Get-FileHash <檔名>`，結果應與同一個 Release 的 `SHA256SUMS.txt` 相同
2. 雙擊執行。若出現 **「Windows 已保護您的電腦」**（SmartScreen）：本程式沒有數位簽章，確認來源是上面的 Releases 頁後，按 **其他資訊 → 仍要執行**
3. 跳出「使用者帳戶控制」（UAC）→ 按 **是**
4. 第一次啟動會顯示**使用條款**：閱讀後勾選「我已閱讀並同意以上條款」→ 按 **同意**。不同意請按「不同意並結束」
   - 條款改版時（通常隨新版本），會再請你確認一次
5. 視窗開啟後會自動搜尋可用的伺服器
6. **關閉視窗 = 中斷連線並恢復一般網路**

視窗上方有三個分頁：**VPN Gate**、**Tor**、**VPNBook**。同一時間只能使用其中一種連線。右上角 ⓘ 是「關於」（版本、更新、回報、條款）。

## 三種連線模式

| | VPN Gate | Tor | VPNBook（選配） |
|---|---|---|---|
| 註冊 | 免 | 免 | 免 |
| 安裝 | 免 | 免（已內建） | 需安裝 WireGuard |
| 速度 | 依伺服器而定 | 較慢 | 較穩定 |
| 涵蓋範圍 | 整台電腦 | 只有會套用 Windows Proxy 設定的程式（主要是瀏覽器） | 整台電腦 |
| 國家 | 清單隨時間輪換 | 依當下出口節點 | 美、加、英、德、法 |

### VPN Gate
- 按 **搜尋伺服器** 後，App 會逐台實際測試，**只列出確定能連的伺服器**；目前沒有伺服器的國家列在下方灰色小字
- 按國家右邊的 **連線** → 頂部顯示「已連線」，底部顯示對外 IP 與「斷線保護：開」
- 清單會隨時間輪換；沒有你要的國家時，過一陣子再搜尋
- VPN Gate 是日本筑波大學的學術研究專案，伺服器由志願者提供，**會保存連線紀錄**（見[隱私與安全提醒](#隱私與安全提醒)）

### Tor
- 按國家右邊的 **連線**，畫面會顯示啟動進度 %；第一次可能要 1～5 分鐘，之後通常 1 分鐘內
- 底部顯示「出口國家」。Tor 會依連線與時間更換線路，所以每次查到的 IP 可能不同，但國家固定
- 只有瀏覽器等會套用 Windows Proxy 設定的程式會走 Tor；其他程式在 Tor 模式下會**連不上**（斷線保護會擋住，不會外洩）
- 許多網站會對 Tor 要求額外驗證或拒絕存取，多數串流平台不支援

### VPNBook（需安裝 WireGuard；設定檔 7 天到期；限個人使用）

#### 第一次使用：取得設定檔
VPNBook 規定每份設定檔要由**使用者本人**勾選同意並通過真人驗證，所以這幾步要你自己點，其他由 App 自動完成（App 不代勾、不模擬點擊、不繞過驗證）。

1. 切到 **VPNBook** 分頁，在要用的國家右邊按 **取得**
2. 會開啟 VPNBook 的網頁（**簡體中文**），App 視窗同時顯示同樣的步驟。依頁面上的區塊由上而下操作：

| 頁面上的區塊 | 你要做的事 |
|---|---|
| 「**选择服务器**」 | 點對應國家的第一台伺服器（見下表） |
| 「**选择端口（UDP）**」 | 保持 **443（HTTPS）**（預設就是） |
| 「**重要信息**」 | 勾選 **我已了解并接受这些条款** |
| 「**生成配置**」 | 完成標題下方的 **Cloudflare 真人驗證**方塊（通常點一下就通過） |
| 驗證方塊下方 | 按藍色按鈕 **生成配置** |
| 出現設定內容與 QR Code 後 | 按 **下载 .conf 文件** |

| 你按「取得」的國家 | 「选择服务器」要點的選項 |
|---|---|
| 美國 | **US Server 1**（us16.vpnbook.com） |
| 加拿大 | **Canada Server 1**（ca149.vpnbook.com） |
| 英國 | **UK Server 1**（uk205.vpnbook.com） |
| 德國 | **Germany Server 1**（de20.vpnbook.com） |
| 法國 | **France Server 1**（fr200.vpnbook.com） |

3. 如果 Edge 右上角問「**您要如何處理 vpnbook-wg_….conf？**」→ 按 **儲存**
4. App 偵測到下載的檔案 → 自動檢查並匯入 → **自動關閉 VPNBook 網頁**
5. 該國卡片變成「設定檔剩 6 天」，按鈕變成 **連線**

> 匯入失敗時，App 會顯示原因並繼續等待；在 VPNBook 頁面再按一次 **下载 .conf 文件** 即可。

#### 到期更新
- 剩不到 24 小時時，卡片文字變黃「剩 N 小時，請盡快更新」；過期後按鈕變回 **取得**，重新走一次上面的流程

#### 安全提醒
- 「下載」資料夾裡的 `vpnbook-wg_….conf` **含有你的私鑰**。App 已複製一份到 `%LOCALAPPDATA%\AIXAI-VPN\vpnbook\`，**下載資料夾的原檔請自行刪除**
- 不要把設定檔或含私鑰的截圖分享給別人；一份設定檔只能用在一台裝置

## 斷線保護
- 連上後自動開啟，底部顯示「斷線保護：開」
- VPN 意外斷線時網路會**暫停**（不會偷偷改走一般網路、不外洩真實 IP），App 自動重新連線
- 想立刻恢復上網：按 **改用一般網路**
- App 結束或當掉時，保護會自動解除、網路自動恢復

## 研究模式
- 主畫面的「研究模式」開關。開啟前會顯示風險說明，按 **我了解，開啟** 才會生效
- 開啟後：VPN 意外斷線時網路保持暫停，每 30 秒自動重試，不顯示「改用一般網路」
- 部分網站（例如串流平台）的條款禁止使用 VPN；在這類網站維持 VPN 連線**可能違反其條款，帳號可能被限制或停權，風險自負**。本工具不會嘗試躲避網站的 VPN 偵測
- 想離開 VPN：按國家卡片上的 **中斷**

## 版本更新與退版
1. 按右上角 ⓘ（有新版本時會出現綠點）
2. 視窗列出所有版本：
   - **更新**：安裝較新的版本
   - **退回此版**：回到舊版本（為避免誤按，要按兩次）
   - 標示「測試版」的是預先發佈版本，可能不穩定
3. App 會下載、核對 SHA256（不符就不安裝），替換執行檔後**自動重新啟動**
- 切換版本前請先**中斷 VPN**
- 「啟動時自動檢查」可關閉；關閉後只在你按「檢查更新」時才連線到 GitHub
- 若防毒軟體攔截或替換失敗，原本的版本會保留；可改到 [Releases](https://github.com/AIXAI-tools/AIXAI-VPN/releases) 手動下載

## 回報問題
1. ⓘ → **回報問題／建議** → 選類型，寫下發生什麼事、怎麼操作會出現（第一行會當作標題）
2. 「附上診斷資訊」會加入版本、Windows 版本、連線狀態與最近紀錄；**IP 位址與使用者資料夾路徑會自動遮蔽**
3. 選擇送出方式（App 只開啟頁面，**不會自動送出**，你確認後自己送）：
   - **用 GitHub**：開啟本專案的 Issues 回報頁（需要 GitHub 帳號）。⚠️ **GitHub Issues 是公開的，任何人都看得到**，請不要寫入姓名、帳號、密碼、私鑰或其他個人資料，截圖前也請遮蔽
   - **用 Email**：開啟你的郵件程式寄給 AIXAI（會讓我們看到你的 Email 地址）
4. 如果沒有自動開啟，按 **複製內容** 後自行貼上

安全性漏洞請勿公開回報，改用 Email（見 [SECURITY.md](../SECURITY.md)）。

## 隱私與安全提醒
- **免費 VPN 不等於匿名**：
  - VPN Gate 會保存連線紀錄至少 3 個月（來源 IP、目的主機與 port、時間等），依法可提供給警察、檢察官或法院；各伺服器也會保存封包標頭；未加密的 HTTP 請求會被加入 VPN 工作階段識別碼
  - Tor 出口節點與 VPN 伺服器營運者可能看到**未加密**的流量
  - 你登入的網站仍然知道你是誰；瀏覽器 Cookie、帳號與指紋不會因為換 IP 而消失
- **請只使用 HTTPS 網站**（網址列有鎖頭），不要透過免費 VPN 傳送敏感資料
- 本工具不收集、不上傳你的任何資料；本機資料位置見[隱私權政策](../PRIVACY.md)
- 使用前請確認所在地法律允許使用 VPN／Tor

## 問題排除
| 狀況 | 處理方式 |
|---|---|
| 網路怪怪的、想全部還原 | 執行 `AIXAI-VPN.exe --restore`（會要求系統管理員權限）：中斷所有 AIXAI-VPN 連線，並還原它改過的 hosts、代理與防火牆設定 |
| 搜尋不到某個國家 | VPN Gate 清單會輪換，稍後再搜尋；或改用 Tor／VPNBook |
| Tor 卡在某個 % | 第一次較久，請等到 5 分鐘；仍失敗就中斷後重試 |
| VPNBook 取得流程卡住 | 查看 `%LOCALAPPDATA%\AIXAI-VPN\vpnbook\vpnbook.log` |
| 更新失敗 | 原版本會保留；到 Releases 頁手動下載新版覆蓋 |
| 其他 | 用 ⓘ →「回報問題」，並勾選附上診斷資訊 |

## 解除安裝
本程式不需安裝；執行期間暫時修改的設定（防火牆規則、hosts、系統代理、WireGuard 通道）會在結束或執行 `--restore` 時還原。移除步驟：
1. 關閉 AIXAI-VPN，執行一次 `AIXAI-VPN.exe --restore`
2. 刪除 `AIXAI-VPN_….exe`
3. 刪除資料夾 `%LOCALAPPDATA%\AIXAI-VPN\`（設定、快取、VPNBook 設定檔與私鑰）
4. Windows「設定 → 網路和網際網路 → VPN」中，移除名為 **AIXAI-VPN-SSTP** 的 VPN 連線
5. 若曾為 VPNBook 安裝 WireGuard 且不再需要，可從「應用程式」解除安裝
6. 刪除「下載」資料夾中殘留的 `vpnbook-wg_….conf`
