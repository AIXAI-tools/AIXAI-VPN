# AIXAI-VPN 使用說明

## 啟動
1. 在專案資料夾開 PowerShell，執行：`python -m src.app`
2. 跳出 Windows「使用者帳戶控制」（UAC）→ 按 **是**（斷線保護需要系統管理員權限）
3. AIXAI-VPN 視窗開啟後會自動搜尋可用的伺服器
4. 關閉視窗 = 中斷連線並恢復一般網路

上方有三個分頁：**VPN Gate**、**Tor**、**VPNBook**。同一時間只能使用其中一種連線。

---

## VPN Gate（免註冊、免安裝）
- 清單上只會出現「目前有伺服器」的國家，沒有的國家列在下方的灰色小字
- 按國家右邊的 **連線** → 連上後頂部顯示「已連線」、底部顯示對外 IP 與「斷線保護：開」
- 清單會隨時間輪換；沒有你要的國家時，過一陣子再按 **搜尋伺服器**

## Tor（免註冊、免安裝；速度較慢）
- 按國家右邊的 **連線**，畫面會顯示啟動進度 %
- 第一次啟動可能要 1～5 分鐘，之後通常 1 分鐘內
- 底部顯示「出口國家」。Tor 會依連線與時間更換線路，所以每次查到的 IP 可能不同，但國家固定
- 只有瀏覽器等會套用 Windows Proxy 設定的程式會走 Tor；多數串流平台不支援 Tor

---

## VPNBook（免註冊；需安裝 WireGuard；設定檔 7 天到期）

### 第一次使用：取得設定檔
VPNBook 規定每份設定檔要由**使用者本人**勾選同意並通過真人驗證，所以這幾步要你自己點，其他由 App 自動完成。

1. 切到 **VPNBook** 分頁，在要用的國家右邊按 **取得**
2. 會跳出 VPNBook 的網頁（**簡體中文**），App 視窗同時顯示同樣的步驟。依頁面上的區塊由上而下操作（頁面上每個區塊左邊有 1～4 的編號）：

| 頁面上的區塊 | 你要做的事 |
|---|---|
| ① 「**选择服务器**」 | 點對應國家的第一台伺服器（見下表） |
| ② 「**选择端口（UDP）**」 | 保持 **443（HTTPS）**（預設就是） |
| ③ 「**重要信息**」 | 勾選 **我已了解并接受这些条款** |
| ④ 「**生成配置**」 | 完成標題下方的 **Cloudflare 真人驗證**方塊（勾選框，通常點一下就通過） |
| ④ 驗證方塊下方 | 按藍色按鈕 **生成配置** |
| 出現設定內容與 QR Code 後 | 按 **下载 .conf 文件** |

| 你按「取得」的國家 | 「选择服务器」要點的選項 |
|---|---|
| 美國 | **US Server 1**（us16.vpnbook.com） |
| 加拿大 | **Canada Server 1**（ca149.vpnbook.com） |
| 英國 | **UK Server 1**（uk205.vpnbook.com） |
| 德國 | **Germany Server 1**（de20.vpnbook.com） |
| 法國 | **France Server 1**（fr200.vpnbook.com） |

3. 如果 Edge 右上角跳出「**您要如何處理 vpnbook-wg_….conf？**」→ 按 **儲存**
4. App 偵測到下載的檔案 → 自動檢查並匯入 → **自動關閉 VPNBook 網頁**
5. 該國卡片變成「設定檔剩 6 天」，右邊按鈕變成 **連線**

> 匯入失敗時，App 會顯示原因並繼續等待；在 VPNBook 頁面再按一次 **下载 .conf 文件** 即可。

### 連線
- 在已取得設定檔的國家按 **連線**

### 到期更新
- 剩不到 24 小時時，卡片文字變成黃色「剩 N 小時，請盡快更新」
- 過期後按鈕變回 **取得**，重新走一次上面的流程

### 安全提醒
- 「下載」資料夾裡的 `vpnbook-wg_….conf` 含有你的私鑰。App 已複製一份到自己的資料夾（`%LOCALAPPDATA%\AIXAI-VPN\vpnbook\`），原檔可自行刪除
- 不要把設定檔或含有私鑰的截圖分享給別人；VPNBook 規定一份設定檔只能用在一台裝置
- VPNBook 限個人使用

---

## 斷線保護
- 連上後自動開啟，底部顯示「斷線保護：開」
- VPN 意外斷線時網路會暫停（不會偷偷改走一般網路），App 自動重新連線
- 想立刻恢復上網：按 **改用一般網路**
- App 若當掉，保護會自動解除、網路自動恢復，不需要手動處理

## 研究模式（上方開關）
- 開啟時會先跳出警告，按「確定」才會開啟
- 開啟後：VPN 意外斷線時網路保持暫停，並每 30 秒自動重試；不顯示「改用一般網路」
- 即使目標網站（例如串流平台）禁止使用 VPN 也維持連線——可能違反該網站條款，帳號風險自負；本工具不會嘗試躲避網站的 VPN 偵測
- 想離開 VPN：按國家卡片上的 **中斷**

## 問題排除
- **網路怪怪的、想全部還原**：在專案資料夾執行 `tools\restore-network.ps1`（會要求系統管理員權限），會中斷所有 AIXAI-VPN 連線並還原它改過的設定
- **VPNBook 取得流程卡住**：查看 `%LOCALAPPDATA%\AIXAI-VPN\vpnbook\vpnbook.log`
